# 🔐 Secure Password Generator

A Python-based secure password generator with a modern Tkinter GUI.  
The application allows users to generate strong passwords based on customizable security requirements.

## 📌 OIBSIP Internship — Task 3

**Track:** Python Programming  
**Task:** Random Password Generator  
**Tier:** Advanced

## 🚀 Features

- 🔑 Generate secure random passwords
- 📏 Password length control from 8 to 50 characters
- 🔠 Include uppercase letters
- 🔡 Include lowercase letters
- 🔢 Include numbers
- 🔣 Include symbols
- 🛡️ Exclude ambiguous characters such as `0`, `O`, `l`, and `1`
- 💪 Password strength indicator
- 📋 Copy generated passwords to clipboard
- 🔐 Uses Python's `secrets` module for secure password generation
- ✅ Guarantees at least one character from every selected character type
- 🕘 Session-only history of the latest 5 generated passwords
- 🖱️ Click a previous password to restore and copy it
- ⚠️ Input validation and error handling
- 🖥️ Maximized and resizable GUI

## 🛠️ Technologies Used

- Python 3
- Tkinter
- secrets
- string
- Pyperclip
